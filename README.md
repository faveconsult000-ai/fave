# Fave Smart SEO

A lightweight SEO command center for ecommerce pages. Enter a public URL to scan core on-page signals and receive an actionable score.

## MVP

- Page title and meta description checks
- H1 detection
- Canonical and robots directives
- Content-depth estimate
- Image alt-text coverage
- Sample internal/external links
- Simple browser dashboard
- Zero runtime dependencies

## Run locally

Requires Node.js 20+.

```bash
npm start
```

Then open `http://localhost:3000`.
